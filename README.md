# 🎨 StickBot — Telegram Bot для создания стикеров и эмодзи

Асинхронный Telegram-бот на **Python 3 (aiogram 3.x)**, позволяющий пользователям мгновенно создавать собственные стикерпаки из любых фотографий, картинок, GIF-анимаций и видео без ручной подгонки под стандарты Telegram.

---

## ✨ Возможности

* 🖼 **Статические стикеры**:
  * Прием любых изображений (фото, файлы, PNG, JPG, WEBP).
  * Автоматическое масштабирование до стандарта Telegram (ровно 512px по одной стороне, $\le$ 512px по второй, с сохранением пропорций через фильтр Lanczos).
  * Контроль веса файла ($< 512$ КБ).
  * Опциональная **белая обводка (контур)** вокруг прозрачных объектов и мягкая тень (стиль стикеров Telegram).
* 🎬 **Видеостикеры**:
  * Прием коротких видео (MP4, MOV) и GIF-анимаций.
  * Автоматическое кодирование в формат **WebM (кодек VP9)** без аудиодорожки.
  * Обрезка до разрешенных 3.0 секунд и частота 30 FPS.
  * Двухпроходное адаптивное сжатие со строгим лимитом размера $\le 256$ КБ.
* ⭐️ **Custom Emoji**:
  * Поддержка создания наборов кастомных эмодзи ($100 \times 100$ px) для пользователей Telegram Premium.
* 🥷 **Функция «Кража стикера» (Sticker Stealer)**:
  * Перешлите боту любой стикер из другого чата или набора — бот моментально клонирует его в ваш активный пак без потери качества.
* ⚡️ **Быстрый режим (Quick Mode)**:
  * Включен по умолчанию: отправка фото $\rightarrow$ мгновенное добавление в активный пак без лишних подтверждений.
  * Кнопка быстрой отмены (удаления последнего стикера) прямо под сообщением с результатом.
* 📂 **Управление наборами (`/packs`)**:
  * Переключение активного пака в один клик.
  * Установка обложки (иконки) пака.
  * Переименование набора.
  * Удаление отдельных стикеров или всего набора.
* ⚙️ **Гибкие настройки (`/settings`)**:
  * Переключение между быстрым режимом и режимом интерактивного предпросмотра.
  * Включение/отключение автоматической белой обводки.
  * Выбор эмодзи по умолчанию.

## 🛠 Технологический стек

* **Язык**: Python 3.12+ / Python 3.14
* **Telegram Framework**: [aiogram 3.31](https://github.com/aiogram/aiogram) (асинхронный FSM, роутинг, типизация)
* **Обработка графики**: [Pillow 13.0](https://python-pillow.org/)
* **Обработка видео**: [FFmpeg](https://ffmpeg.org/) (кодирование `libvpx-vp9`)
* **База данных**: SQLite с режимом **WAL** через [aiosqlite](https://github.com/omnilib/aiosqlite)
* **Контейнеризация**: Docker & Docker Compose

## 🚀 Локальный запуск

### 1. Клонирование репозитория
```bash
git clone git@github.com:Vokiry/stickbot.git
cd stickbot
```

### 2. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Откройте `.env` и укажите ваш токен бота от [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
DB_PATH=data/bot.db
TEMP_DIR=/tmp/stickbot
LOG_LEVEL=INFO
```

### 3. Запуск через Python venv
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

### 4. Запуск через Docker Compose
```bash
docker compose up -d --build
```

## 🧪 Запуск тестов

Тестовый набор включает проверку алгоритмов пропорционального ресайза, белой обводки, валидации имен паков, извлечения эмодзи, конвертации видео в VP9 WebM и операций БД:

```bash
pytest -v
```
